Bornes asymétriques possibles : ex. XY + = 0.010 et XY − = 0.020 accepte un écart Dx/Dy entre −0.020 et +0.010. Saisir la même valeur des deux côtés pour une tolérance symétrique classique (± identique).
Commentaire
Nom / prénom du signataire
Tolérances : valeur invalide (doit être > 0) pour les composantes activées.
Règle métier
Écarts : Dx = Xmes − Xcalc ; Dy = Ymes − Ycalc ; Dz = Zmes − Zcalc.
STATUT : VALIDE si toutes les composantes activées respectent les tolérances (−Tol XY− ≤ Dx, Dy ≤ Tol XY+ ; −Tol Z− ≤ Dz ≤ Tol Z+). Sinon REFUSÉ.
